# NexFin Wallet — Modern FinTech & Crypto Asset Portfolio App

A cross-platform Flutter application designed with dark-mode glassmorphic aesthetics, featuring real-time financial tracking, multi-asset crypto holdings, interactive transaction management, and expense analytics.

---

## 🚀 Key Features

- **Dynamic Financial Dashboard**: Real-time total balance, monthly profit metrics, and quick action transfers (Send, Receive, Swap).
- **Multi-Asset & Card Management**: Multi-card horizontal carousel and crypto portfolio tracking with live status indicators.
- **Analytics & Expense Breakdown**: Category-wise expense tracking, monthly performance metrics, and transaction history.
- **Interactive State Architecture**: Reactive state management handling real-time balance calculations, transaction additions, and modal actions.
- **Glassmorphic UI/UX**: Custom dark-theme glassmorphism, fluid micro-interactions, responsive bottom navigation, and Material 3 design system.

---

## 🛠️ Tech Stack & Architecture

- **Framework**: Flutter (Dart SDK ^3.13)
- **Design System**: Material 3, Custom Glassmorphic Shadows, Google Fonts
- **State Management**: InheritedWidget / ChangeNotifier-based reactive architecture
- **Platforms**: Android, iOS, Web, macOS, Windows, Linux
